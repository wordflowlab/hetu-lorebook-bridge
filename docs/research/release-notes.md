# 世界书互通 v0.1.0

让角色卡和世界书在不同创作工具之间有据交换，保留未知字段，明确转换损失。

固定 JSON／PNG／CHARX 原文件 → 解析并记录摘要 → 审阅角色和条目 → 调整字段映射 → 准备宿主设定候选 → 原格式往返核对。专业动作可由Codex通过河图稳定CLI/MCP调用，包内Skill随安装发现；桌面提供审阅、意见和固定成果交接。

验证：河图v0.11.11正式签名公证安装包的macOS arm64独立CI通过，覆盖全部声明动作、Skill资源、启停卸载重装、CAS、历史与原键恢复，以及全部页签浅暗／窄窗、真实导出和关闭重开。

源码、运行包、归档与目录摘要及安装证据一并固定。最低宿主0.11.11；Windows/Linux专业旅程、创作质量、声音权利／人工听读、正文采纳与定稿未由本次自动验收证明。
